Rencana dulu, tulis kemudian

Mode Plan membaca proyek dan menyusun rencana tanpa mengubah satu file pun. Aturan hanya-baca ini ditegakkan di kode, bukan lewat prompt, jadi model tidak bisa melanggarnya. Kalau rencananya cocok, pindah ke Build.

Kamu tetap memegang kendali

Agent boleh bekerja cepat, tetapi setiap langkah yang berisiko berhenti dulu di depanmu.

Diff dan konfirmasi
Sebelum file ditulis, kamu melihat diff-nya dan menyetujuinya.
Batas workspace
Agent bekerja di folder proyek. Akses ke luar workspace meminta konfirmasi, atau beri izin lebih dulu dengan --allow-path.
Checkpoint dan undo
Perubahan dicatat sebagai checkpoint, dan /undo [n] mengembalikannya.
File sensitif
.env, kunci privat, serta folder .ssh dan .aws selalu meminta konfirmasi eksplisit, bahkan saat memakai --allow-all. Di mode non-interaktif, aksesnya ditolak.
Batas langkah dan biaya
--max-steps dan --max-cost menghentikan tugas yang melebar, dan pengulangan yang sama ikut dibatasi. Skripmu mengetahuinya dari kode keluar 3.

Pakai model dari penyedia yang kamu mau

NeX-Agent memakai arsitektur multi-provider, dengan adapter untuk API yang kompatibel dengan OpenAI dan untuk Anthropic. Hubungkan penyedia dengan /connect, lalu pilih model dari daftar bernomor atau ketik nama modelnya sendiri.

Di mode chat

/connect
/models        daftar model bernomor
/models 2      pilih nomor 2
/models 0      model custom, ketik namanya
/usage         rekap token dan biaya

Diingat per workspace

Pilihan model disimpan di config.json, jadi model custom tetap terpakai setelah restart. Kredensial ada di berkas terpisah dan tidak pernah dicetak.

Ajari agent lewat satu file SKILL.md

Skill adalah folder berisi SKILL.md dengan frontmatter name dan description. Formatnya sama dengan skill Anthropic seperti frontend-design, keluaran SkillUI, dan skill Strix.

Hanya name dan description yang masuk ke system prompt, jadi murah. Saat tugas cocok, model memanggil tool skill untuk memuat instruksi lengkapnya.

skills/ringkas/SKILL.md

---
name: ringkas
description: Ringkas dokumen panjang menjadi poin-poin
---

Saat diminta meringkas:
1. Baca sumber dengan read_file.
2. Tulis maksimal 7 poin, masing-masing < 20 kata.

Lokasi yang dipindai

~/.config/agent/skills/<nama>/SKILL.md
<workspace>/skills/<nama>/SKILL.md
<workspace>/.nex-agent/skills/<nama>/SKILL.md

Kontrol manual: /skills, /skill <nama>, /skill off, atau --no-skills.

Pasang dengan satu perintah

Installer memasang Node 20+ dan pnpm bila belum ada, mengunduh sumber, membangun, lalu memasang perintah nex-agent (alias agent). Mau memeriksa isinya dulu? Baca install.sh sebelum menjalankannya.

  1. Jalankan installer

    curl -fsSL https://raw.githubusercontent.com/RydzzKen/NeX-Agent/main/install.sh | bash

  2. Muat ulang shell, cukup sekali

    source ~/.bashrc

  3. Mulai, lalu setup penyedia saat pertama kali

    nex-agent

Di Termux, pasang git lebih dulu. Perintah langsung dipasang ke $PREFIX/bin, jadi tidak perlu memuat ulang shell.

pkg install -y git

Setup pertama: hubungkan penyedia

Saat pertama dijalankan, NeX-Agent memandu setup lebih dulu: pilih penyedia, isi API key, lalu daftar model dideteksi langsung dari penyedia itu. Untuk layanan yang kompatibel dengan OpenAI, pilih Custom dan isi nama serta Base URL.

Pertanyaan yang sering muncul

Di mana kredensial disimpan?

Di ~/.config/agent/credentials.json dengan izin 600. Isinya tidak pernah dicetak atau ditulis ke log.

Bagaimana kalau agent salah mengubah file?

Setiap perubahan lewat diff dan konfirmasi, dan tercatat sebagai checkpoint. Jalankan /undo untuk mengembalikannya.

Bisa dipakai di skrip atau CI?

Bisa. --json mengeluarkan event mentah dan --yes menyetujui konfirmasi. Kode keluar membedakan sukses (0), gagal tugas (1), error konfigurasi (2), batas terlampaui (3), dan interupsi (130). Akses ke file sensitif tetap ditolak di mode non-interaktif.

Bisa dipakai di HP?

Bisa, lewat Termux di Android. Installer memakai pkg untuk memasang Node dan pnpm.

Butuh Node versi berapa?

Node.js 20 atau lebih baru. Bila belum ada, installer memasangnya lewat nvm di Linux dan macOS tanpa sudo, atau lewat pkg di Termux.
